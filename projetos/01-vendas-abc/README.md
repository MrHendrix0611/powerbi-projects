# ABC Equipamentos — Análise de Vendas

![Capa do relatório](ABC%20Equipamentos%20Home.png)

## Objetivo

Explorar o desempenho comercial de uma empresa de equipamentos por meio de indicadores de receita, produtos, clientes e vendedores, com segmentações para apoiar a análise de resultados.

## Conteúdo

- Evolução das vendas e indicadores gerais.
- Análise de desempenho por produto, região e vendedor.
- Páginas para explorar produtos e realizar pesquisas.
- Navegação entre áreas do relatório.

## Arquivos principais

- **`Vendas.pbix`** — relatório do Power BI.
- **`Vendas.csv`**, **`Clientes.csv`**, **`Produtos.csv`**, **`Vendedores.csv`**, **`Calendario.csv`** — fontes de dados originais.
- Arquivos PNG — imagens e recursos do dashboard.

## Como abrir

Abra `Vendas.pbix` no Power BI Desktop. Caso a atualização solicite uma origem de dados, ajuste os caminhos dos CSVs para a pasta deste projeto e execute **Atualizar**.
