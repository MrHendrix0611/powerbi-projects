# VAREON Intelligence 360

**Commerce & Retail | Painel de Gestão Estratégica — 2024 a 2025**

![Prévia visual das páginas](preview/v3_visao_geral.png)

## Objetivo

Reunir em uma única solução de Business Intelligence indicadores de vendas, rentabilidade, entregas e experiência do cliente de uma operação de e-commerce. O projeto apresenta uma jornada de análise da visão executiva até a identificação de prioridades operacionais.

## Dashboards

| Página | Análise |
|---|---|
| **00 — Capa** | Apresentação e navegação principal |
| **01 — Visão Executiva** | Receita, pedidos, ticket médio, margem e regiões |
| **02 — Inteligência Comercial** | Produtos, categorias, segmentos e comportamento de compra |
| **03 — Desempenho Logístico** | Entregas, prazos, frete e atrasos |
| **04 — Experiência do Cliente** | Avaliações e relação entre satisfação e entregas |
| **05 — Intelligence Lab** | Indicadores cruzados para priorização de oportunidades |

O projeto utiliza menus laterais, navegação entre dashboards, filtros e identidade visual própria.

## Tecnologias e arquivos

- **`CommerceIntelligence360.pbip`** — ponto de abertura do projeto no Power BI Desktop.
- **`CommerceIntelligence360.Report/`** — definições das páginas e dos visuais (PBIR).
- **`CommerceIntelligence360.SemanticModel/`** — medidas, tabelas e relacionamentos (TMDL).
- **`data/`** — fontes CSV de consulta e referência.
- **`preview/`** — prévias gráficas do design; não substituem a renderização do relatório no Power BI Desktop.

## Como abrir

1. Utilize uma versão atualizada do Power BI Desktop com suporte a projetos PBIP.
2. Abra **`CommerceIntelligence360.pbip`**.
3. Verifique o carregamento do modelo e das seis páginas.
4. Se necessário, atualize o relatório e valide botões e segmentações.

O estudo utiliza uma empresa e uma base de dados demonstrativas. As páginas e o modelo semântico estão definidos dentro do projeto.
