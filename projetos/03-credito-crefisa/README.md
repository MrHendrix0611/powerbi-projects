# Crefisa — Análise de Operações de Crédito

![Capa do relatório](Capa%20Crefisa.jpg)

## Objetivo

Analisar indicadores relacionados a operações de empréstimo, valores contratados e distribuição das operações, com exploração por produtos, filiais e períodos.

## Conteúdo

- Indicadores de operações de crédito e valores financeiros.
- Visualizações por modalidade, unidade e período.
- Elementos gráficos e navegação entre telas.

## Arquivos principais

- **`Crefis14.pbix`** — relatório completo do Power BI.
- **`BD/Base-Emp.xlsx`** — planilha de dados utilizada no exercício.
- **`Capa Crefisa.jpg`**, **`Back Dash Crefisa.png`**, **`Background Dash Crefisa Drill.jpg`**, **`Logo Crefisa.png`** — imagens e fundos do relatório.

## Como abrir

Abra `Crefis14.pbix` no Power BI Desktop. Se for solicitada a localização da planilha, configure a origem para `BD/Base-Emp.xlsx` e atualize as consultas.
